# Fotos einfügen (für den MacBook)

Alle Fotos der Seite sind als Platzhalter vorbereitet. So ersetzt du sie:

1. **Datei ablegen:** in den Ordner `public/images/` legen, z. B. `public/images/hero.jpg` (JPG, PNG oder WebP, gern WebP).
2. **Eintragen:** in `src/data/site-images.ts` den Pfad und den Alternativtext (Deutsch und Englisch) setzen, z. B.
   `hero: { src: "/images/hero.jpg", alt: { de: "Eine Katze auf dem Fensterbrett", en: "A cat on the windowsill" } }`
3. **Blogbild:** in der Markdown-Datei des Beitrags im Kopf `image: "/images/blog/dateiname.jpg"` ergänzen.
4. Wenn du mir die Dateien schickst, mache ich das für dich.

| Platz | Format | Mindestgröße |
|---|---|---|
| Startseite (Hero) | Hochformat 4:5 | 1200 × 1500 px |
| Produktwelten (4 Stück) | 4:3 | 1200 × 900 px |
| Geschichte (Startseite) | 4:3 | 1200 × 900 px |
| Über uns (Foto von euch) | Hochformat 4:5 | 1200 × 1500 px |
| Blogbeitrag | 3:2 | 1200 × 800 px |

Bildsprache: natürliches Licht, warme neutrale Töne, ruhige Alltagsmomente, kein harter Filter. Dateigröße möglichst unter 500 KB.
